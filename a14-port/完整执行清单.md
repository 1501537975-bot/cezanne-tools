## 四、完整刷机流程

### 步骤 0：准备（已就绪）
```bash
# 内核    D:\cezanne-work\artifacts\extracted\artifacts\*-gz-anykernel3.zip
# super   D:\cezanne-work\rebuild\super_cezanne.img
# ramdisk D:\cezanne-work\rd_work\ramdisk.img
# dtbo    原厂 (绝不能用移植包的!)
```

### 步骤 1：组装 boot.img
```bash
cd a14-port
python3 make_boot.py \
  --orig    "D:/cezanne-work/firmware/.../images/boot.img" \
  --kernel  "D:/cezanne-work/artifacts/extracted/.../kernel/Image.gz" \
  --ramdisk "D:/cezanne-work/rd_work/ramdisk.img" \
  --out     "D:/cezanne-work/boot_cezanne.img"
```

### 步骤 2：进 fastboot
```bash
adb reboot bootloader
fastboot devices
fastboot getvar product      # cezanne
fastboot getvar unlocked     # yes
fastboot getvar slot-count   # 0 (A-only)
```

### 步骤 3：刷入
```bash
# ★ dtbo 必须用原厂 —— MT6889 != MT6893, 刷错硬件全废
fastboot flash dtbo   "原厂 dtbo.img"
fastboot flash boot   "D:/cezanne-work/boot_cezanne.img"
fastboot flash super  "D:/cezanne-work/rebuild/super_cezanne.img"

fastboot --disable-verity --disable-verification flash vbmeta        "原厂 vbmeta.img"
fastboot --disable-verity --disable-verification flash vbmeta_system "原厂 vbmeta_system.img"

fastboot erase userdata
fastboot erase metadata
fastboot reboot
```

### 步骤 4：验证
```bash
adb shell uname -r                                  # 4.14.186-perf-00252-g2f26b5917fd6
adb shell getprop sys.boot_completed                 # 1
adb shell cat /proc/filesystems | grep erofs         # erofs
adb logcat -b all | grep -iE "avc: denied|erofs|ext4-fs error"
```

## 五、风险清单

| 风险 | 说明 | 缓解 |
|---|---|---|
| **变砖** | MT6889 极难救 | ① 备份已做 ② 准备**可解密 recovery** |
| dtbo 刷错 | MT6893 的 dtbo 会让硬件全废 | **只用原厂 dtbo** |
| vendor 不匹配 | 移植包 vendor 是 MT6893 | 脚本已自动用原厂 |
| fstab fs 类型 | 写 ext4 但实际 EROFS → 卡开机 | 脚本已自动改 erofs |
| vermagic 不匹配 | 内核串不对 → 原厂 .ko 加载失败 | 自编内核已对齐原厂串 |
| **缺 EROFS 驱动** | 内核没这驱动 → 挂载不了 system | **必须用第 33 轮的产物** |
